# Color Palette

Official colors for Hackster Niko.

| Color Name | Hex | Suggested Use |
| --- | --- | --- |
| Hackster Blue | `#47C7FF` | Primary brand accent, UI-inspired glow, Niko details |
| Core Crystal | `#63DFFF` | Energy core, crystals, magical tech highlights |
| Hoodie Blue | `#2E8CFF` | Clothing, strong blue accents, cover contrast |
| Friendly White | `#F8FCFF` | Niko surfaces, highlights, clean backgrounds |
| Dark Outline | `#394A63` | Gentle outlines, readable detail, text-adjacent contrast |
| Golden Gear | `#F2C94C` | Hidden object, warm highlights, rewards |
| Dragon Green | `#6BCB5B` | Password Dragon, friendly creature accents |
| Forest Green | `#3FAF64` | CyberForest, natural tech environments |

## Palette Rules

- Keep colors bright, friendly, and readable in print.
- Use `Dark Outline` instead of pure black for softer children's book linework.
- Use `Friendly White` for Niko's clean robot surfaces.
- Reserve `Golden Gear` for special warm accents and the hidden object.
- Check contrast for small text and activity pages.

## Print Notes

Colors may shift between RGB art files and CMYK print output. Always review proofs before approving final print files.
