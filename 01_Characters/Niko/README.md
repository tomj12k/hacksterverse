# Hackster Niko

## Character Summary

Hackster Niko is a small friendly learning robot.

- Model: HN-01
- Height: 2'6"
- Age equivalent: 7
- Pronouns: he/him
- Role: Junior Hackster
- Catchphrase: "Every problem has a clever fix!"

## Personality

Niko is kind, curious, creative, and brave in a childlike way. He likes patterns, puzzles, helping friends, and learning how things work.

He should feel capable but not perfect. Niko can misunderstand, try the wrong fix first, ask for help, and learn out loud.

## Design Notes

- Rounded friendly robot shapes with softly realistic storybook depth.
- Expressive glowing robot eyes.
- Bright Hackster Blue and Core Crystal accents.
- Friendly White body surfaces.
- Dark Outline for soft readable linework.
- No weapon-like attachments.
- Gadgets should look helpful, safe, and toy-like.
- Final book art should not use the simple flat-vector pose renders unless explicitly approved as a fallback.

## Gadget Rules

Niko's gadgets are learning tools, not weapons. They should help him observe, measure, organize, communicate, or create.

Examples:

- Clue scanner
- Kindness compass
- Pattern pad
- Glow wrench
- Password helper card
